# ORDYXIS - オンラインオーダーシステム

チュロス専門店向けのオンラインオーダーシステムです。
お客様の端末 (iPhone / iPad など) から注文し、お店のPCで注文を受けて番号でお呼び出しする流れを Firebase Realtime Database でリアルタイム共有します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `customer.html` | お客様側 (メニュー選択 → カートで注文確認 → 注文番号の受け取り → 提供完了の操作)。売り切れ商品は注文不可。順番が来ると通知＋バイブ＋音でお知らせ。受け取りはスライド＋確定ボタンの2段階。提供前にアプリを閉じても、再度開くと注文内容と番号を自動復元 |
| `store.html` | お店側 (タブ式: 準備中／呼出中／完了済み／売上・集計／在庫設定)。商品ごとの注文可能数(上限)を設定でき、上限到達で自動的に売り切れに。売上・注文数・販売個数を集計表示。iPhone/iPad でも見やすいレスポンシブ表示。ハンバーガーメニュー(☰)から通知音設定・履歴削除 |
| `monitor.html` | 番号案内モニター (お呼び出し中の番号と商品準備中の番号を大きく表示。新たに呼ばれた番号を**音声でアナウンス**。店頭ディスプレイ用) |
| `app-common.js` | 共通処理 (スプラッシュ画面・メニュー定義・データ層) |
| `firebase-config.js` | Firebase の接続設定 (要編集) |
| `img/` | 画像フォルダ (下記のPNGを配置してください) |

## 1. 画像の配置 (必須)

`img` フォルダに以下のファイル名でPNG画像を保存してください。

**商品画像**
- `Ordyxis_MC_Chocolate.png` … チュロス チョコレート (¥700)
- `Ordyxis_MC_Cinnamon.png` … チュロス シナモン (¥700)
- `Ordyxis_MC_Plain.png` … チュロス プレーン (¥700)
- `Ordyxis_MD_Cola.png` … コーラ (¥500)
- `Ordyxis_MD_Orange.png` … オレンジジュース (¥500)

**ロゴ画像 (スプラッシュ画面・サイトアイコン用)**
- `NGX.png` … NGX ロゴ
- `MagicalFuture.png` … Magical Future ロゴ
- `Ordyxis.png` … ORDYXIS ロゴ (サイトアイコン/faviconにも使用)

※ 画像が無い場合でも、グレーのプレースホルダー表示で動作確認は可能です。

## 2. Firebase の設定

1. [Firebase コンソール](https://console.firebase.google.com/) で新規プロジェクトを作成
2. 「構築 > Realtime Database」からデータベースを作成 (ロケーションは任意、テストモードで開始)
3. 「プロジェクトの設定 > マイアプリ > ウェブアプリ (</>)」でアプリを追加し、表示される `firebaseConfig` の値を `firebase-config.js` にコピー
4. `databaseURL` が含まれていることを確認 (Realtime Database のURL)

**セキュリティルールの例** (運用時はテストモードのままにせず、最低限以下を設定してください):

```json
{
  "rules": {
    "orders":   { ".read": true, ".write": true },
    "counters": { ".read": true, ".write": true }
  }
}
```

> 本格運用では Firebase Authentication (匿名認証など) と組み合わせ、書き込み内容の検証ルールを追加することを推奨します。

### Firebase 未設定の場合 (デモモード)

`firebase-config.js` が未設定でも **デモモード** で動作します。
同じブラウザで `customer.html` と `store.html` を別タブで開くと、タブ間で注文が共有されます (端末間の共有はFirebase設定が必要です)。

## 3. 起動方法

ローカル確認はファイルをそのままブラウザで開いても動きますが、簡易サーバーの利用を推奨します:

```
cd ORDYXIS
python -m http.server 8000
```

- お客様側: `http://<PCのIPアドレス>:8000/customer.html` (iPhone/iPad からアクセス)
- お店側:   `http://localhost:8000/store.html` (お店のPC)
- モニター: `http://<PCのIPアドレス>:8000/monitor.html` (店頭の番号案内ディスプレイ)

公開する場合は Firebase Hosting (`firebase deploy`) が手軽です。

## 4. 注文の流れ

1. **起動**: NGX / Magical Future / ORDYXIS のロゴとロードバーのスプラッシュ画面から開始
2. **お客様**: メニューから商品を選択 → カートで内容と合計を確認 → 「この内容で注文する」
3. **お客様**: 注文番号 (例: No. 001) を受け取り、状況をリアルタイム表示 (受付済み・準備中)
4. **お店**: 「新規注文」列に受付順で表示 → 商品ができたら「番号を呼び出す」
5. **お客様**: 画面が「お呼び出し中！」に変わる → カウンターで商品を受け取る
6. **お客様**: 順番が来ると通知・バイブ・音でお知らせ → カウンターで商品を受け取る
7. **お客様**: 「スライドして受け取り完了」を右端までスライド → 表示された「受け取り完了（確定する）」ボタンをもう一度押して取引完了 (誤操作防止の2段階)
   (操作忘れの場合はお店側の「手動で完了にする」でも完了できます)

注文番号は日付ごとに 001 からの連番で自動採番されます。

## 5. お知らせ / 更新内容（プレ版アップデート）

- **注文可能数（在庫）の設定**: 店舗用の「在庫設定」タブから商品ごとに本日の注文可能数（上限）を設定できます。上限に達した商品はお客様の画面で自動的に「SOLD OUT（売り切れ）」表示になり、注文できなくなります。残り個数はお客様にも表示されます（空欄／「無制限」で上限なし）。設定は全端末へ即時反映されます。
- **売上・集計タブ**: 店舗用に「売上・集計」タブを追加。本日の売上金額・注文件数・販売個数に加え、商品別の販売数と売上を一覧表示します。
- **完了済みを別タブへ**: 完了した注文は「完了済み」タブに分離し、準備中・呼出中の画面がすっきりしました。
- **モニターの音声呼び出し**: 番号案内モニターで、新しく呼ばれた番号を音声でアナウンスします（例:「番号、12番のお客様、カウンターまでお越しください」）。初回のみ画面の「音声案内を有効にする」ボタンを押してください（ブラウザの仕様）。ヘッダーのボタンでON/OFF切替できます。
- **順番が来たら通知**: お客様の画面で、お呼び出し時に通知・バイブレーション・通知音でお知らせします（通知は端末の許可が必要です）。
- **2段階の受け取り確認**: お客様の受け取り完了操作を「スライド」＋「受け取り完了ボタンの再確認」の2段階にし、誤操作を防ぎます。
- **iPhone / iPad 対応**: 店舗用画面をタブ式・レスポンシブにし、スマホ・タブレットでも崩れず表示されるよう改善しました（セーフエリア対応）。
