📘 ダウンロードって、何をしているの？ 押すと①から順に進みます
  1. くらべるサーバーにある最新の一覧と、いまスマホに入っているデータを1件ずつつき合わせます。ここでは通信量はほとんど使いません。
  2. 変わったぶんだけ落とす中身が変わったファイルだけを取りにいきます。前と同じファイルは落とし直しません——だから「約○○MB」より実際はずっと小さくなります。
  3. スマホに保存する落としたデータをスマホの中にしまいます。これが終わると機内モード・電波なしでも MagiLex / MagiBurst / MagiChainParty などが遊べます。
  4. 最新版に切り替える画面を自動で読み込み直して完了。セーブデータ（進行・所持キャラ・XEVA）はそのままです。

    「約 ○○ MB」と出るのに、実際はもっと少ないのはなぜ？

    この数字はつき合わせる対象ぜんぶの大きさ（＝最大値）です。実際に落とすのは 中身が変わったファイルだけなので、ほとんどの回はこの何分の一かで終わります。 進み具合の下に出る「更新したファイル ○件（○MB）」が本当に落とした量です。

    更新を何回か見送ったら、そのぶん重くなる？

    なりません。見送った回数に関係なく、いまのスマホの中身と最新をくらべて足りないぶんだけを 1回で取り込みます。見送った回の「更新内容」は、まとめてこの画面に並びます。

    ギガ（通信量）が心配。モバイル回線でも大丈夫？

    2回目からは差分なので少量ですみますが、初回だけはまとまった量になります。 はじめての更新と「オフライン用に再ダウンロード」は Wi-Fi をおすすめします。 途中で通信が切れても、次に開いたときに続きからそろえ直せます。

    「あとで」を押したらどうなる？

    そのまま遊べます。ただしオフラインのときは古い版のままになります。 あとで 設定 → アプリの更新 からいつでも実行できます。

    ダウンロードしたのに、機内モードで開けない

    スマホの空き容量が減ると、保存したデータが自動で捨てられることがあります。 そのときは版が最新のままなので「アプリの更新」では直りません。 設定 → オフライン設定 → オフライン用に再ダウンロード を実行すると、 欠けているファイルだけを取り直して直せます（セーブデータはそのまま）。

    セーブデータが消えたりしない？

    消えません。ダウンロードするのはアプリのプログラムと画像だけで、 進行・所持キャラ・XEVA・ジェムは別に保存されています。 アカウントでログインしていれば、機種変更のときもクラウドから引き継げます。
