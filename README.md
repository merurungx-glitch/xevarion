# XEVARION

**NGX × Magical Future がお届けする、次世代アプリポータル。**

XEVARION（ゼヴァリオン）は、NGX と Magical Future が手がける数々のアプリを、
ひとつの場所から楽しめる統合ポータルサイトです。
チャットや学習、音楽、ゲームまで――ジャンルを越えたアプリたちが、ここに集います。

---

## このサイトでできること

XEVARION のトップページから、各アプリへワンタップでアクセスできます。
気になるアプリを選んで、そのまますぐに使い始められます。
最新のお知らせや更新情報も、サイト上でいつでもチェックできます。

アプリは大きく **MagiOne シリーズ** と **MeruHub シリーズ** の 2 つのラインで展開しています。

---

## MagiOne シリーズ

魔法のような体験を届ける、コミュニケーション＆ゲームアプリのコレクション。
つながり、学び、競い、楽しむ。

| アプリ | ジャンル | 紹介 |
|---|---|---|
| **MagiLink** | メッセージ | 友達やグループと、スタイリッシュにつながるチャットアプリ。 |
| **MagiLex** | クイズ・学習 | あらゆるジャンルの問題に挑戦。知識を楽しく深める学習アプリ。 |
| **MagiTier** | Tier 表・プレゼン | カードを並べ替えて、自分だけのランキングを世界へ発信。 |
| **MagiArena** | ボードゲーム | サイコロを振り、コインを集めて仲間と競う魔法のアリーナ。 |

## MeruHub シリーズ

学習・音楽・ゲームをひとつのエコシステムへ。
生産性と娯楽を融合させた、次世代ユーティリティのコレクション。

| アプリ | ジャンル | 紹介 |
|---|---|---|
| **StudyGuard** | 学習管理 | 学習計画・進捗・達成をトラッキングする、勉強の頼れる盾。 |
| **AudioX** | 音楽プレイヤー | ビジュアライザーを備えた、没入感あふれる Web ミュージックプレイヤー。 |
| **WordbookX** | 単語帳 | スマートな反復学習で、語彙の習得を加速する単語帳。 |
| **TAKAGAME** | オリジナルゲーム | 炎の翼をまとったタカが飛び立つ、唯一無二のオリジナルゲーム。 |

## ORDYXIS（プレ版）

NGX × Magical Future が贈る、店頭オンラインオーダーシステム **ORDYXIS** を、
現在 **プレ版として限定公開中** です。

お客様の端末から注文し、お店で受付・番号でお呼び出し、店頭モニターで案内――
注文の流れをリアルタイムにつなぎます。**お客様用 / 店舗用 / モニター用**の
3 つの画面をご用意しています。

> プレ版のご利用には、アクセスコードの入力が必要です。
> コードは関係者へ別途ご案内しております。
